# [新手教程]如何使用 WandB 监控大模型的训练与调试

> 来源（Source）：https://my.feishu.cn/wiki/Lf7Kw0QzciE9vzkqEZKcc3vOnNc

大家在刚开始跑模型的时候，可能只是盯着终端里滚动的 loss 看。但单纯的数字很难让我们直观地判断模型的状态：是过拟合了？还是学习率太大了？

WandB (Weights & Biases) 就是为了解决这个问题而生的，它能把枯燥的数据变成可视化的图表。今天这篇新手教程，主要想帮大家解决两个问题：**如何配置**和**如何解读**。

## 如何配置

#### **第一步：注册与获取API key**

登录官网：https://wandb.ai/注册账号

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/Kp4mbMEI7oy59jxOvxxcgkaRnrh.png)

取到自己的api key：

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/S89MbObZzoaIhFxlUkNcqFR5nVc.png)

#### **第二步：安装与登录**

在我们运行代码的服务器上安装wandb

打开命令行，输入：

```python
pip install wandb
```

安装后即可登录wandb，在命令行输入：

```python
wandb login
```

并根据提示输入API key。

#### **第三步：代码埋点**

只需要在训练中加一行代码，就能记录你关心的所有指标（Loss, Accuracy, Length 等），例如：

```python
wandb.log({
    "val/test_score": test_score,  # 评测集准确率
    "actor/pg_loss": actor_pg_loss,  # 策略梯度损失
    "actor/kl_loss": actor_kl_loss,  # KL散度
    "critic/rewards/mean": mean_reward,  # 平均奖励
    "actor/entropy_loss": actor_entropy_loss,  # 熵损失
    "response_length/mean": mean_response_length,  # 平均回复长度
    "response_length/clip_ratio": clip_ratio,  # 回复截断比例
})
```

之后即可在wandb home的主页上看到训练过程。

## 如何解读

本文以[DeepScaleR样例](https://wandb.ai/mluo/deepscaler-1.5B/workspace?nw=nwusermluo)为例，讲解如何查看强化学习实验记录指标。DeepScaleR的核心是解决**小型语言模型通过强化学习提升推理能力时的效率与效果平衡问题**，提出了 “迭代上下文延长” 策略，成功训练出参数仅 1.5B 但推理性能比肩大模型的 DeepScaleR-1.5B。

为了看懂后面的图，我们需要知道 DeepScaleR 的训练策略：

- **模型**：基于 1.5B 模型进行 GRPO 微调。
- **策略**：采用**迭代式上下文延长 (Iterative Context Lengthening)**。
- **阶段**：先在 **8K** 长度训练，然后拓展到 **16K**，最后到 **24K**。就像教学生，先让他写短文，再让他写长篇大论 。

接下来，我们把 WandB 里的曲线分成三类来解读，分别是：

- 第一维度：它变强了吗？（性能指标）
- 第二维度：它学得稳吗？（训练稳定性指标）
- 第三维度：它在想什么？（行为模式指标）

### 第一维度：它变强了吗？（性能指标）

#### 关注指标：`val/test_score` (评测集准确率)

看下图的阶梯式上升：

不同颜色的线代表不同阶段，我们可以清晰地看到，随着上下文窗口的拉长（从8K到16K再到24K），模型的准确率**基线和峰值是逐步提高的，**这说明模型解决难题（AIME2024）的能力在稳步提升。这也直接证明了论文提出的**迭代上下文长度延长**（Iterative Context Lengthening）策略的有效性。

### 第二维度：它学得稳吗？（训练稳定性指标）

#### 1. `actor/pg_loss` (策略梯度损失)

这张图反映了模型策略（Policy）更新的有效性。简单来说，`pg_loss` 衡量的是**“模型当前的决策”与“理想的高分决策”（由优势函数指导）之间的差距**。

图中展示了两种特点：

- **波动中下降**： 与 SFT 阶段平滑的 Loss 不同，RL 训练由于数据分布的动态变化，Loss 曲线通常伴随剧烈震荡。不过只要它大体在下降，就说明模型正在根据奖励信号不断优化自己的解题步骤。
- **分阶段收敛**：
    - **8K 阶段 (蓝线)**：作为冷启动阶段，Loss 下降最快，表明模型在短窗口下迅速建立了基础推理模式
    - **16K (红线) -> 24K (粉线)**：可以观察到**迁移性**。当上下文窗口扩大时，Loss 并没有出现发散或剧烈反弹，而是保持了收敛的连续性。这证明了模型在短文本习得的优势策略，成功**泛化（Generalize）**到了长文本空间，通过 24K 阶段进一步巩固了长程推理能力。

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/W2nPbUKjCoivKXxjWfCcObaQnee.png)

#### 2. `actor/kl_loss` (KL 散度)

**KL Loss 衡量的是当前模型策略与参考策略（通常是上一阶段的模型）之间的分布差异**。在强化学习中，它起到了**限制每次参数更新幅度**的作用。我们希望模型在优化 Reward 的同时，不要偏离旧策略太远，以防止训练崩溃或发生灾难性遗忘。

从下图可以看出：

- **8K 阶段 (蓝线)** ： 我们可以看到蓝线在训练过程中显著上升，KL 值一度达到 0.4。这说明在训练初期，为了学会如何推理（Reasoning），模型正在对基础策略进行大幅度的调整和修正 。此时的高 KL 值是符合预期的，代表模型正在走出舒适区，建立全新的解题范式。
- **16K & 24K 阶段 (红/粉线)** ： 与之形成鲜明对比的是，红色和粉色曲线始终维持在极低的水平（接近 0）。这证明了**能力迁移**的发生： 当上下文扩展到 16K 和 24K 时，模型并没有从头学起，而是直接继承了 8K 阶段已经学好的推理逻辑，仅针对长文本进行微小的适应性调整。这种“低 KL、高 Reward”的状态，正是课程学习（Curriculum Learning）策略成功的最佳佐证。

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/F8Y4buKLLoKsJ1xtQVbcJzA6ngd.png)

#### 3. `critic/rewards/mean` (平均奖励)

DeepScaleR 采用了简单但有效的奖励函数，不使用中间奖励：

- 如果模型生成的答案正确，并且通过了 LaTeX/Sympy 检查，则获得奖励 **1**。
- 如果答案不正确或格式不当，则奖励为 **0**。

由于奖励是二元的 (1 或 0)，平均奖励值实际上反映了模型在当前阶段的平均成功率或近似准确率。

从下图可以看出：

模型首先在成本较低的 8K 语境中快速获得大量奖励提升，当上下文窗口增加到 16K 和 24K 时，平均奖励并没有从头开始，而是保持了高位。这表明 DeepScaleR 的 RL 训练能够有效地将已获得的推理能力（高奖励策略）无缝地扩展到更长的上下文长度。

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/HE39bWQc8oHyF6xanUZcjcdqnse.png)

### 第三维度：它在想什么？（行为模式指标）

#### 1. `actor/entropy_loss` (熵/探索欲)

**策略熵是模型在生成下一个token时，其概率分布的分散程度**。熵越高表示模型对于下一步的选择越具探索性，其概率分布比较分散，倾向于尝试多种不同的推理路径。熵越低表示模型对于下一步的选择更确定。熵损失表示熵的平均值，用于衡量策略模型的探索性。

从下图可以看出：

模型在 8K 和 16K 阶段 提高探索性（高熵）以学习有效的推理模式，从而实现性能的飞跃。在性能达到高水平后（24K 阶段），模型会降低探索性（低熵），迅速将策略收敛到最优、最确定的解题方法上。

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/MgUgbgHBcolMfPx4GDKcw4pgnQA.png)

#### 2. `response_length` (回复长度) & `clip_ratio` (截断比例)

`response_length`衡量的是在RL训练的每一步中，生成的**平均输出长度。**clip_ratio**衡量的是模型输出超过当前上下文窗口的回复的比例**，如下图所示在8k上下文训练前期，回复长度逐渐降低（在clip_ratio降低），但在训练400步左右开始上升，8k上下文限制了进一步的性能提升，于是将上下文提升到16k，最后又拓展到24k。

这说明：

在8k训练初期，模型学会了**高效地推理，**惩罚了不必要的冗余输出，导致长度迅速下降。后来模型识图通过更长的思考来提升训练奖励，导致clip_ratio上升，此时8k的上下文窗口成为了限制模型训练的因素。将上下文窗口到16k后，模型输出长度逐渐增加，准确率也有一定的提升。最后将上下文长度提升到24k。

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/SaKhbpPneonC4IxmUzPc0qcLnKd.png)

![]([新手教程]如何使用%20WandB%20监控大模型的训练与调试/images/Fksnby1J5ozZoRxnJarclZ7Cneg.png)

## 总结

借助 WandB 的全链路监控，我们将 DeepScaleR 的训练过程从黑盒转化为了一套可观测的系统。通过对各项指标的复盘，验证了以下假设：

- **策略有效性** ：准确率随 Context 长度阶梯式上升。
- **训练稳定性**：Loss 下降，Reward 稳定。
- **行为演化** ：从广撒网（高熵）到精细化推理（低熵、长CoT）。

希望本新手教程能帮你快速读懂自己的实验数据，每一次训练都能心中有数~
